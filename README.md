# LLM Code Quality Comparison

A data pipeline that compares Python code generated by different large language models (LLMs) across a set of standardized coding tasks. Each model's output is evaluated against Python quality metrics and compiled into a dataset for analysis.

## Pipeline

```
tasks/tasks.json
  → pipeline/generate_response.py   # Query each LLM API, save raw JSON
  → data/raw/{model}/               # Raw API responses
  → pipeline/extract_code.py        # Extract Python code from JSON
  → data/processed/{model}/         # Clean .py files
  → pipeline/run_metrics.py         # Compute LOC + Pylint metrics
  → data/metrics/dataset.csv        # Final dataset for analysis
```

## Getting Started

**1. Clone the repo and set up the environment**
```bash
git clone <repo-url>
cd llm_comparison
python -m venv .venv
.venv\Scripts\activate       # Windows
pip install -r requirements.txt
```

**2. Add your API keys**

Create a `.env` file in the project root:
```
ANTHROPIC_API_KEY=your_key_here
OPENAI_API_KEY=your_key_here
```

**3. Run the full pipeline**
```bash
python main.py
```

Or run individual steps:
```bash
python -m pipeline.generate_response   # Step 1: Query LLMs
python -m pipeline.extract_code        # Step 2: Extract code
python -m pipeline.run_metrics         # Step 3: Compute metrics
```

## Models

Responses are generated via API (not the web UI) to ensure deterministic, non-personalized outputs.

| Model | API | Notes |
|---|---|---|
| ChatGPT | OpenAI Chat Completions | Default general-purpose model |
| Claude | Anthropic Messages | Sonnet 4.6 |

General-purpose chat models are used intentionally — the goal is to reflect how most users interact with these tools day-to-day, not to benchmark specialized coding models.

## Tasks

Tasks span two categories:

| Task | Category |
|---|---|
| `palindrome_check` | DSA |
| `binary_search` | DSA |
| `rest_api_endpoint` | System Design |
| `task_scheduler` | System Design |

Task definitions live in `tasks/tasks.json`. Each task includes a `task_id`, `prompt`, and `category`.

## Metrics

| Metric | Description |
|---|---|
| `loc` | Non-blank lines of code |
| `pylint_errors` | Error-level violations |
| `pylint_warnings` | Warning-level violations |
| `pylint_refactor` | Refactor suggestions |
| `pylint_convention` | PEP 8 style violations |
| `pylint_total` | Total violations |

## Output

`data/metrics/dataset.csv` — one row per model per task:

| model | task | run | loc | pylint_errors | pylint_warnings | pylint_refactor | pylint_convention | pylint_total |
|---|---|---|---|---|---|---|---|---|
| chatgpt | binary_search | 1 | 11 | 0 | 0 | 1 | 3 | 4 |
| claude | binary_search | 1 | 15 | 0 | 0 | 1 | 3 | 4 |
